# Short-Term Memory

Version: 1.0.0

---

# Purpose

Stores the active conversation and recent events.

---

# Lifetime

- Seconds
- Minutes
- Current Session

---

# Stores

- User Messages
- AI Responses
- Temporary Variables
- Active Commands
- Current Files
- Running Tasks

---

# Capacity

```
4K–128K Tokens
```

Configurable depending on model.

---

# Pipeline

```
Input

↓

Cache

↓

Reasoning

↓

Discard or Promote
```

---

# Promotion Rules

Important information moves into

- Episodic Memory
- Semantic Memory
- Long-Term Memory

---

# Summary

Acts as the AI's immediate attention span.
