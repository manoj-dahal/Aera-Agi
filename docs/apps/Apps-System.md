# Overview

The Apps System is AERA's unified application management framework.

It provides a centralized environment where desktop applications, development tools, AI software, creative software, utilities, plugins, and custom applications can be launched, monitored, automated, and controlled by AI agents.

Unlike a traditional launcher, the Apps System understands application state, project context, permissions, performance, and inter-application communication.
