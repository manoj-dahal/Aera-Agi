# Animation

Version: 1.0.0

---

# Overview

Animation controls every movement of the AERA avatar.

Animations are generated procedurally using conversation context, emotions, and user interaction.

---

# Animation Types

- Idle
- Speaking
- Listening
- Thinking
- Greeting
- Pointing
- Typing
- Walking
- Sitting

---

# Animation Pipeline

```
Context

↓

Animation Planner

↓

Animation Controller

↓

Avatar Skeleton

↓

Renderer
```
