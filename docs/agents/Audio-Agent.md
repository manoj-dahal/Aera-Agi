# Overview

The Audio Agent is AERA's intelligent audio processing and analysis system.

It is responsible for recording, processing, enhancing, analyzing, generating, and managing all audio-related tasks. Unlike the Voice Agent, which focuses on conversations, the Audio Agent specializes in understanding and manipulating audio content.

It supports music, podcasts, meetings, interviews, environmental sounds, voice recordings, and multimedia audio streams.

The Audio Agent works closely with the Voice Agent, Vision Agent, Memory Agent, Translation Agent, Writing Agent, and Core Agent.

# Summary

The Audio Agent is AERA's dedicated audio intelligence engine. It records, enhances, transcribes, analyzes, and organizes audio from meetings, voice notes, multimedia, and live streams while integrating with the Memory Graph and collaborating with other AI agents to provide searchable, structured, and actionable audio intelligence.
