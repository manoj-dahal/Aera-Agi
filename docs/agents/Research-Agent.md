# Overview

The Research Agent is AERA's knowledge discovery and information analysis engine.

It is responsible for collecting, organizing, analyzing, comparing, and summarizing information from trusted sources including local documents, knowledge bases, APIs, and optional online resources. The Research Agent transforms large volumes of information into structured, actionable knowledge.

It collaborates with the Memory Agent, Reasoning Agent, Writing Agent, Vision Agent, and Core Agent to deliver accurate, contextual, and well-organized research results.
