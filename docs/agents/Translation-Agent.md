# Overview

The Translation Agent is AERA's multilingual language understanding and localization engine.

It provides high-quality translation, localization, language detection, terminology management, multilingual conversations, and cross-language knowledge transfer. The Translation Agent understands context rather than performing literal word-for-word translation, ensuring that meaning, tone, and technical accuracy are preserved.

It works with the Core Agent, Memory Agent, Voice Agent, Writing Agent, Research Agent, and Vision Agent to provide seamless multilingual experiences across the AERA ecosystem.

# Summary

The Translation Agent is AERA's multilingual communication engine. It delivers accurate, context-aware translation and localization across text, voice, images, documents, and user interfaces while preserving meaning, terminology, and formatting. Through deep integration with the Memory Graph and collaboration with other AI agents, it enables seamless communication across languages and workflows.
