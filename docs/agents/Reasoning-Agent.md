# Overview

The Reasoning Agent is AERA's analytical intelligence engine.

It specializes in logical reasoning, multi-step problem solving, decision analysis, hypothesis evaluation, and complex knowledge synthesis. The Reasoning Agent transforms information from multiple agents into coherent conclusions and recommendations.

Rather than storing information like the Memory Agent or executing tasks like the Coding Agent, the Reasoning Agent focuses on understanding relationships, evaluating evidence, identifying patterns, and producing well-supported conclusions.

It works continuously with the Core Agent to improve the quality and accuracy of AI responses.

By combining structured reasoning with evidence evaluation and multi-agent collaboration, it enables AERA to solve complex problems with transparency, consistency, and reliability.
