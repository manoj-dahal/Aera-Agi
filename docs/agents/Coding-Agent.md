# Overview

The Coding Agent is AERA's software engineering specialist.

It assists with software development throughout the entire software development lifecycle (SDLC), including planning, architecture, implementation, debugging, testing, optimization, documentation, deployment, and maintenance.

The Coding Agent collaborates with the Core Agent, Terminal Agent, Git Agent, Workspace Agent, Memory Agent, and Reasoning Agent to provide an intelligent development experience.
