# Overview

The Learning Agent is AERA's adaptive intelligence and continuous learning engine.

It is responsible for learning user preferences, improving workflows, recognizing patterns, understanding habits, optimizing AI behavior, and continuously enhancing AERA's intelligence through experience.

Unlike traditional machine learning systems, the Learning Agent does **not** modify foundation models directly. Instead, it builds structured knowledge, preference profiles, workflow patterns, reusable skills, and semantic relationships that improve future interactions while keeping the user in control.

The Learning Agent collaborates closely with the Memory Agent, Planning Agent, Reasoning Agent, Workspace Agent, and Core Agent.
