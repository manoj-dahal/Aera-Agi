# Overview

The Vision Agent is AERA's computer vision and visual intelligence specialist.

It enables AERA to understand, analyze, interpret, and reason about visual information including images, screenshots, documents, diagrams, user interfaces, videos, and camera feeds.

The Vision Agent collaborates with the Memory Agent, Coding Agent, Research Agent, Workspace Agent, Voice Agent, and Core Agent to transform visual data into structured knowledge.

# Summary

The Vision Agent is AERA's visual intelligence engine. It transforms images, documents, screenshots, videos, and live camera input into structured knowledge through OCR, object recognition, document understanding, and semantic analysis. By integrating with the Memory Graph and collaborating with other agents, it enables AERA to understand and reason about visual information as naturally as text.
