# Overview

The Writing Agent is AERA's professional writing and content generation specialist.

It assists users in creating, editing, rewriting, formatting, reviewing, and optimizing written content across technical, academic, business, and creative domains. The Writing Agent adapts its writing style, structure, and tone based on the user's intent while maintaining clarity, consistency, and accuracy.

It collaborates with the Memory Agent, Research Agent, Translation Agent, Coding Agent, Planning Agent, and Core Agent to produce context-aware, high-quality written content.
